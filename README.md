# Aura Clinic - Healthcare & Dental Website

A customizable, patient-centered static clinic website ready for zero-cost hosting on **GitHub Pages**.

## Highlights
- **Appointments Bag**: Persistent localStorage visits bag with cancellation dispatcher and automatic WhatsApp alerts to the clinic desk.
- **Client Customization Suite**: White-label control panel allowing instant rebranding for Dental Clinics, Dermatology, or Pediatrics.
- **Featured Care Matrix**: 3-column line-art specialty layout with expandable service accordions.
- **Patient & Facility Gallery**: Lightbox image modal with category filtering.
- **Verified Feedback**: Real patient testimonials and review submissions.

## Zero-Cost GitHub Pages Deployment
1. Create a free GitHub repository.
2. Upload this `index.html` file to the repository's `main` branch.
3. In your repo: **Settings** -> **Pages** -> Source: **Deploy from a branch** (`main` / `/root`).
4. Your site will immediately be live!
